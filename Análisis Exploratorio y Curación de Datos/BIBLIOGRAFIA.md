# Análisis Exploratorio y Curación de Datos — Bibliografía Complementaria

## Libros

### VanderPlas, J. (2016). *Python Data Science Handbook* (1st ed.). O'Reilly Media
- **Capítulos**: 2 (NumPy) y 3 (Pandas)
- **Acceso gratuito**: https://jakevdp.github.io/PythonDataScienceHandbook/
- **Uso sugerido**: base de NumPy/Pandas para EDA, manipulación de datos, indexado, groupby, merge/join.

### Géron, A. (2019). *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* (2nd ed.). O'Reilly Media
- **Capítulo**: 2 (End-to-End Machine Learning Project)
- **Uso sugerido**: pipeline completo de ML — incluye preparación de datos, manejo de faltantes, encoding, transformaciones y pipelines de scikit-learn.

### Molinaro, A. & de Graaf, R. *SQL Cookbook* (2nd ed.). O'Reilly Media
- **Uso sugerido**: recetario de consultas SQL — útil para Clase 4 (combinación de datasets / SQL).
