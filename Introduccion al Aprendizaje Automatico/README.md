# Introduccion al Aprendizaje Automatico

Carpeta preparada para materiales FaMAF 2026.

## Estructura

- `clases/`: material oficial descargado o descargable. Esta carpeta debería quedar ignorada en git.
- `manifest.md` / `manifest.json`: trazabilidad curso → FaMAF → archivo local o acción manual.

- `TP2/`: faltante detectado en el repo activo; el notebook oficial queda en `clases/notebooks/Evaluación/` hasta que se copie o adapte.
